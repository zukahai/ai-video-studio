# HaiAI Studio (Video • Image • AI Director)

Nền tảng Web Studio sáng tạo đa phương tiện **HaiAI** hỗ trợ:
- 📊 **Dashboard Tổng quan:** Thống kê số lượng video, ảnh, chuỗi cảnh phim và quản lý tác phẩm vừa tạo.
- 🎬 **HaiAI Video Studio:**
  - Chọn đa tỉ lệ khung hình: `16:9` (YouTube), `9:16` (TikTok/Reels), `1:1` (Vuông), `21:9` (Điện ảnh Ultrawide), `4:3`.
  - **Tạo Video Nối Tiếp (Sequential Storyboard):** Tạo chuỗi các cảnh phim liên tiếp giữ nguyên nhân vật, bối cảnh và ánh sáng.
  - **Tự động nâng cấp Prompt ẩn:** Hệ thống tự động bổ sung các chỉ dẫn đạo diễn chuyên nghiệp 4K, ánh sáng, chuyển động camera và âm thanh đồng bộ ở tầng ngầm (ẩn hoàn toàn với người dùng).
- 🎨 **HaiAI Image Studio:** Tạo ảnh nghệ thuật độ phân giải cao với 5 tỉ lệ khung hình và ảnh tham chiếu.
- 💬 **Trợ lý Đạo diễn & Biên kịch HaiAI:** Tư vấn kịch bản nhiều phân cảnh và chuyển nhanh sang tạo Video/Ảnh chỉ với 1 cú nhấp.

---

## 🚀 Cách khởi động ứng dụng

### Khởi động nhanh (1-Click)
* Nhấp đúp vào file **`start.bat`** trong thư mục dự án.
* Trình duyệt sẽ tự động mở **`http://localhost:7860`**.

### Khởi động bằng dòng lệnh
```powershell
.\.venv\Scripts\python.exe server.py
```
