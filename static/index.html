Hướng dẫn lấy Chat ID / Group ID Telegram
1. Lấy ID cá nhân (Chat riêng với Bot):

• Mở Telegram, tìm @userinfobot hoặc @RawDataBot rồi bấm Start để xem dòng Id (VD: 123456789).

• Quan trọng: Mở chính Bot của bạn (tạo ở mục 1) và bấm Start (/start) ít nhất 1 lần thì Bot mới gửi được tin nhắn cho bạn.

2. Lấy ID Nhóm (Group) / Kênh (Channel):

• Thêm Bot của bạn vào nhóm (nếu là Channel, cấp quyền Admin đăng bài cho Bot) và nhắn 1 tin bất kỳ vào nhóm.

• Cách nhanh: thêm @RawDataBot vào nhóm để lấy trường "chat": {"id": ...}, hoặc mở link https://api.telegram.org/bot<TOKEN>/getUpdates để xem ID (ID nhóm thường bắt đầu bằng - hoặc -100...).
